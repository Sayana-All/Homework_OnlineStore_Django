# Homework_OnlineStore_Django
### Создание онлайн-магазина с помощью фреймворка Django

## Описание
Продолжаем работу над проектом интернет-магазина. 
Всё больше пользователей веб-сервиса, над которым вы работаете, пользуются реализованной платформой, и администраторы начинают замечать проблемы со скоростью. Проведенное нагрузочное тестирование выявило проблемы, с которыми необходимо разобраться.

## Инcтрукции
+ Настроите кеширование в вашем веб-приложении, используя Redis в качестве брокера для хранения данных в памяти. Это позволит повысить производительность сайта и уменьшить нагрузку на базу данных.
+ Реализуете кеширование для страницы продукта, что обеспечит более быструю загрузку информации при повторных запросах.
+ Создадите сервисную функцию, которая будет получать список всех продуктов в заданной категории, и отобразите эту информацию на отдельной странице сайта.

## Задачи
1. Установите Redis как брокер для кеширования. Настройте проект для использования Redis и убедитесь, что всё работает правильно с новыми настройками.

2. Настройте кеширование для страницы, которая отображает информацию об одном продукте.

3. Создайте сервисную функцию для работы с продуктами, которая будет возвращать список всех продуктов в указанной категории. 
Реализуйте отдельное представление и шаблон для отображения этой информации на сайте.

4. Добавьте низкоуровневое кеширование для списка продуктов.
